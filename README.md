# Amazon S3 Static Website Hosting with CI/CD

This project demonstrates how to host a static website on AWS S3 and deploy it automatically using a CI/CD pipeline.

## 🚀 Architecture
GitHub → AWS CodePipeline → CodeBuild → Amazon S3

## 🛠️ AWS Services Used
- Amazon S3 (Static Website Hosting)
- AWS CodePipeline (CI/CD)
- AWS CodeBuild
- IAM

## 📌 Features
- Automated deployments on every GitHub commit
- Secure IAM roles and policies
- Scalable and cost-effective static hosting
